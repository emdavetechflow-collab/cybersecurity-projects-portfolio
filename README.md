Cybersecurity Engineering Portfolio
Engineering Philosophy
The modern cyber defense landscape requires shifting from reactive monitoring to proactive, automated engineering. My work addresses this critical industry need by building systems that shift security left, automate incident response, and validate defensive capabilities before adversaries strike. This portfolio demonstrates my ability to not just operate security tools, but to architect, automate, and scale them.
Portfolio Pillars
DevSecOps & Secure Infrastructure Engineering: Engineering CI/CD pipelines (GitHub Actions, Trivy, Gitleaks) to autonomously block vulnerable code, and implementing Secure IaC (Terraform/Checkov) to ensure cloud environments are hardened against misconfiguration before deployment.
Cloud Security & Zero Trust Architecture: Developing custom CSPM tools (Python/Boto3) to auto-remediate critical cloud exposures, and enforcing Zero Trust identity verification at the application layer, aligning with modern federal and enterprise mandates.
Threat Detection, Automation & Incident Response (SOAR): Deploying custom SIEM threat hunters and SOAR playbooks (VirusTotal API) to automate phishing triage and malware detonation, reducing analyst response time from hours to seconds. Authoring vendor-neutral SIGMA detection rules deployable across any enterprise SIEM.
Offensive Validation & Deception Technology: Conducting Purple Team simulations to validate defensive telemetry, and deploying custom Deception Technology (Honeypots) to gather threat intelligence on attacker TTPs.
